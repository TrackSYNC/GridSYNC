Publish

  1. Click Export schedule.js. Your browser downloads the file.
  2. In the GitHub repository, open the data folder, choose Add file then Upload files, drop in schedule.js, and commit.
  3. GitHub Pages republishes the participant page, usually within a few minutes.

Nothing on this page is public until the exported file is committed to the repository. Only people with write access to the repository can publish.
